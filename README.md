# Site de beleza & bem-estar — FEELING GOOD (projeto de demonstração)

Site fictício desenvolvido como peça de portfólio para o nicho de **beleza & bem-estar**
(cabeleireiros, barbearias, spas, esteticistas e afins que precisam de mostrar serviços,
preços e trabalhos realizados).

🔗 **Demo ao vivo:** _(adicionar link do GitHub Pages depois do deploy)_

## Sobre o projeto

"FEELING GOOD" é um estúdio fictício de beleza e bem-estar em Luanda, com serviços de
cabelo, manicure/pedicure, tratamentos de pele, massagens e barbearia. O objetivo do
site é transmitir elegância e sensorialidade, mostrar a tabela de serviços com preços
e o portfólio de trabalhos, e converter visitas em marcações via WhatsApp.

## Stack

- HTML5 semântico
- CSS3 puro (sem frameworks) — variáveis CSS para o sistema de design
- JavaScript vanilla (acordeão de serviços, galeria masonry, menu mobile)
- Tipografia: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) + [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)

## Nota sobre as imagens

As imagens usadas são fotografias reais do [Unsplash](https://unsplash.com), livres de
direitos, relacionadas com o tema (cabelo, unhas, spa, ambiente de salão). Num projeto
real para cliente, seriam substituídas por fotografias reais do espaço e da equipa.
